Unrush

The assistant that speaks first, before your evening falls apart.

3-minute demo · with sound Amazon Bedrock · Nova 2 Lite AgentCore Memory MCP 2025-11-25 · Streamable HTTP MCP Apps · Agent Skills

It speaks first

A late meeting lands. Unrush works out when to leave and finds a dinner that still fits, before anyone asks.

Groceries from your usuals

It predicts what runs out, picks the products you usually buy, and asks only about the new one.

Nothing bought without a yes

Checkout is simulated and needs an explicit yes. Each product links to its real Amazon page; no card data is ever handled.

It remembers

Household state lives in a self-hosted MCP server, and the conversation in Amazon Bedrock AgentCore Memory.
