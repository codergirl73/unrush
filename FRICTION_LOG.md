# Friction Log

This log records real friction hit while building Unrush with the **MCP TypeScript SDK** (`@modelcontextprotocol/sdk` 1.32.1, spec 2025-11-25, Streamable HTTP) and **Amazon Bedrock** (Converse API, `@aws-sdk/client-bedrock-runtime`). Entries 1–6 were hit while building this codebase's MCP layer, which Unrush reuses. Later entries were hit during the Unrush build.

**Severity:** 🔴 blocker · 🟠 significant slowdown · 🟡 minor annoyance · ⚪ cosmetic / docs

| 1 | MCP SDK: server | Log the negotiated protocol version at session init (a hard requirement: prove 2025-11-25 is used) | Looked for a getter on `McpServer` / `Server`, then read `dist/esm/server/index.js` | **Expected:** something like `server.getNegotiatedProtocolVersion()`; the client transport has `transport.protocolVersion`. **Actual:** `Server._oninitialize` computes the version and returns it inline. | 2 | MCP SDK: types | Work out which version the server negotiates by default | Read `types.d.ts` | **Expected:** `DEFAULT_NEGOTIATED_PROTOCOL_VERSION` to be what a fresh client/server pair negotiates. **Actual:** it is `2025-03-26`, but negotiation really yields `LATEST_PROTOCOL_VERSION` (`2025-11-25`). The constant is only the HTTP transport's fallback when the `mcp-protocol-version` header is missing, so it briefly looked like a downgrade. | ⚪ | Read the transport source to confirm | Rename it (e.g. `HTTP_FALLBACK_PROTOCOL_VERSION`) or add a JSDoc comment |
