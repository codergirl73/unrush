# Friction Log

This log records real friction hit while building Unrush with the **MCP TypeScript SDK** (`@modelcontextprotocol/sdk` 1.32.1, spec 2025-11-25, Streamable HTTP) and **Amazon Bedrock** (Converse API, `@aws-sdk/client-bedrock-runtime`). Entries 1–6 were hit while building this codebase's MCP layer, which Unrush reuses. Later entries were hit during the Unrush build, including MCP Apps (`@modelcontextprotocol/ext-apps`), the Strands Agents SDK evaluation and Amazon Bedrock AgentCore.

**Severity:** 🔴 blocker · 🟠 significant slowdown · 🟡 minor annoyance · ⚪ cosmetic / docs
